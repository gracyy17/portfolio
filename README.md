# Portfolio Website

A modern, animated personal portfolio website built with React and Vite.

## Features

- Animated pulse effect in the landing page background
- About and Portfolio sections with pulse + sliding light effects
- Auto-advancing project slider
- Responsive layout for desktop and mobile
- Smooth section reveal animations and active navigation states
- Ready for GitHub Pages deployment with a Vite build

## Run Locally

1. Install dependencies with `npm install`
2. Start the dev server with `npm run dev`
3. Build a production bundle with `npm run build`
4. Preview the production build with `npm run preview`

## Deploy To GitHub Pages

1. Run `npm run build`.
2. Deploy the contents of `dist/` to GitHub Pages.
3. The Vite config already uses a relative base path for subpath hosting.

## Customize

- Update content in `src/App.jsx`
- Change colors and animation timing in `src/styles.css`
- Replace project card images in `src/styles.css` (`.image-1`, `.image-2`, `.image-3`)
- Update social and email links in `src/App.jsx`
